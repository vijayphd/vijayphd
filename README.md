## Dr. Vijayakumar P

Assistant Professor. I teach HR analytics, business analytics and performance management to MBA and EMBA cohorts, and I publish the teaching material openly instead of keeping it behind a course login.

I came to management from engineering: a B.Tech in electronics and communication, then an MBA in HR and marketing, a spell as an ML Data Associate on Amazon's Alexa team, and a Ph.D. in Management earned as a UGC Junior and Senior Research Fellow.

### Start here

Code and material you can clone, run and teach with. The code repositories use synthetic or public data, so everything can be shared freely.

### Research

What performance pressure does to employees, traced down two paths: unethical pro-organizational behaviour on one side, creative work involvement on the other. Mixed methods, scale development, EFA and CFA, measurement invariance, SEM.

### Free tools

**[Analytics Lab](https://yuvijen.com/data-analytics/).** Browser-based entry points to RStudio, Jupyter, Colab, Kaggle, jamovi and Looker Studio, so a class can start analysing on any machine with nothing installed, plus sample code to get the first cell running.

**[Journal Indexes](https://journalindexes.com).** Search 52,000 journals by name, ISSN, topic or author, then check Scopus quartile, Web of Science collection, ABDC rating, DOAJ status and predatory flags before you submit. Free, no account.
